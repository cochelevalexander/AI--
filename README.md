Тестовый сервис для генерации карточек товаров для B2B-интернет магазина.

Стек: 
Nuxt
Flask
GigaChat
Docker


Для запуска склонируйте репозиторий: 
git clone https://github.com/cochelevalexander/AI--.git

Перейдите в папку: 
cd AI--

Запустите сборку проекта, используя собственный api-токен сбера:
$env:API_KEY="ваш_реальный_ключ"; docker compose up --build
